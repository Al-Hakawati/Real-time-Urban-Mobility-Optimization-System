# Real-time Urban Mobility Optimization System 🚦

An integrated system that combines AI models, a Flask-based dashboard, and a Spring Boot backend to manage and optimize urban traffic in real-time.

## 📁 Project Structure

- `ai-models/` – Computer vision and reinforcement learning for traffic analysis.
- `frontend-flask/` – Web dashboard and Flask API layer.
- `springboot-backend/` – Backend services and MongoDB integration.
